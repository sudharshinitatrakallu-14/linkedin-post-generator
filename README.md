# AI-Powered LinkedIn Post Generator

## Overview
This project automates the creation and publishing of LinkedIn posts using Groq AI and Pipedream.

## Technologies
- Groq AI
- Pipedream
- LinkedIn API
- Cursor AI

## Workflow
Trigger → Groq AI → LinkedIn Post

## Features
- AI-generated professional content
- Automated LinkedIn publishing
- Workflow automation
